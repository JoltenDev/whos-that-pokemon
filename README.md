# Who's That Pokémon?!

Welcome to a browser based Pokémon silhouette guessing game!


## How to Play

1. **Observe the Shadow:** A wild silhouette appears on screen!
2. **Make Your Guess:** Type the Pokémon's name into the **Guess** box.
3. **Lock It In:** Press the **Guess** button to see if you're right!
4. **Keep the Streak Going:** Hit **New Pokemon** to summon another wild pokemon from the tall grass.


## Tech Stack & Structure

Built by D'Antay Hawkins, Pokemon Fraud:

* **HTML5:** Semantic structure keeping the Pokédex screen organized.
* **CSS3 (`style.css`):** Styling and silhouette creation.
* **JavaScript (`script.js`):** All the game logic, guess checking, and Pokémon-summoning power.
